## 👋 Visão geral

O **Study Hub** é meu espaço de organização acadêmica e desenvolvimento profissional durante a graduação em **Engenharia de Software no Centro Universitário de Brasília (CEUB)**.

Este repositório reúne, de forma estruturada e versionada, materiais de estudo, atividades acadêmicas, anotações, projetos e certificados. A proposta é transformar o aprendizado em um histórico organizado de evolução — da compreensão dos fundamentos à construção de soluções práticas.

> **Propósito:** conectar conhecimentos de gestão e tecnologia para desenvolver soluções de software organizadas, úteis e orientadas a problemas reais.

## 🎯 Objetivos

- Organizar atividades, entregas, anotações e resumos por disciplina.
- Praticar documentação técnica e boas práticas de organização de projetos.
- Aprender e aplicar o versionamento com Git e GitHub.
- Desenvolver uma página web para apresentar o Study Hub.
- Construir gradualmente um portfólio acadêmico e profissional verificável.
