## 🎯 Objetivo desta seção

Reunir estudos e práticas relacionados à modelagem, estruturação, consulta e integridade de bancos de dados relacionais.

## 📚 Conteúdos de referência

- Conceitos de bancos de dados relacionais.
- Entidades, atributos e relacionamentos.
- Modelo Entidade-Relacionamento (MER) e diagramas (DER).
- Modelagem lógica e chaves.
- Fundamentos da linguagem SQL.
- Consultas, filtros, ordenação e operações de manipulação de dados.
- Integridade e organização dos dados.

Adicionar scripts SQL, diagramas, exercícios de modelagem e consultas produzidas durante a disciplina. Não incluir credenciais nem dados pessoais reais.
